# Bangladesh Grid Data

A repository for Bangladesh power grid data and analysis.

## Overview

This project contains data and tools related to the Bangladesh electrical grid infrastructure.

## Getting Started

To get started with this project, clone the repository and explore the available data and tools.

```bash
git clone https://github.com/sunrisesineast/bangladesh-grid-data.git
cd bangladesh-grid-data
```
